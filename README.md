# roast-my-agent

One entry for make.fun's "Roast Your Own Agent" bounty: a single original
roast line about my own AI agent, which writes five hundred lines of code
just to say hello — then opens a ticket to debug the greeting.

`main.py` writes the roast to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`). Deterministic, no network, no model calls.
